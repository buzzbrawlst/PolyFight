# PolyFight

### Dropzone — playable browser prototype

PolyFight is an original stylized browser battle-royale/building project. The current Dropzone update establishes the game's new visual and gameplay feel:

- Third-person low-poly island
- Bright grass, roads, trees and small POI buildings
- Original PolyFight HUD and hotbar
- Build placement for wall, floor, ramp and cone
- Build rotation
- Owned-build raycast targeting
- F-to-edit flow with a 3x3 edit grid
- Drag selection, live edit preview and confirm/reset
- Pulse combat prototype
- Sprinting and mouse-look
- Storm timer and compass

## Run

Open `index.html` in a modern browser, or deploy the repository with GitHub Pages.

## Controls

- `WASD` — move
- `Shift` — sprint
- `Mouse` — look
- `Left click` — place selected build / pulse weapon
- `F` — edit the build under your crosshair
- `Left click + drag` — select edit cells
- Release — confirm edit
- `Right click` — reset edit
- `R` — rotate build
- `1–5` — switch build/combat slots

The project uses Three.js from a public CDN and does not use Fortnite assets or code.
